# Streamlit

Streamlit es una librería de Python que permite crear aplicaciones web de manera rápida y sencilla.
Ejecuta el código de manera secuencial de igual manera que un script de python en consola, 
La sintaxis es sencilla con la unica diferencia que proporciona una interfaz web mas amigable
y mas orientada a visualizacion de datos.
